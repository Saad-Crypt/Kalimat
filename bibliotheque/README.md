# Ma Bibliothèque — application Android

Application de gestion de bibliothèque, utilisable hors connexion.

## Fonctions
- Catalogue des livres : titre, auteur, ISBN, éditeur, année, genre, emplacement et notes.
- Recherche et filtres par catégorie.
- Gestion des emprunteurs et des prêts/retours.
- Tableau de bord avec statistiques.
- Export et import des données au format JSON.
- Données conservées localement sur l'appareil.

## Compilation APK
Le workflow GitHub Actions **Build Bibliotheque APK** se lance automatiquement après une modification du dossier `bibliotheque/`, ou manuellement depuis l'onglet Actions.

L'APK de test est publié comme artefact sous le nom **bibliotheque-apk**.
